# Бронь · Фотостудия Томсон

PWA-приложение для быстрого создания и отправки сообщений о бронировании залов.

## Как использовать

1. Выберите зал (Сфера / Эдисон / Вегас)
2. Заполните имя, телефон, количество гостей, дату и время
3. Выберите **статус оплаты** (`-` ждём / `.` 50% / `..` 100%)
4. При необходимости отметьте эмодзи-теги (танцы, спот, школьники и т.д.)
5. На вкладке **Бронь** — отправьте сообщение клиенту
6. Нажмите **📅 Добавить в Календарь** — создастся событие с правильным заголовком
7. После получения чека → смените статус на `.. 100%` → снова добавьте в календарь (старое можно удалить)
8. Для MAX — текст копируется, откройте приложение и найдите по номеру

## Установка на телефон (PWA)

- **Android (Chrome)**: откройте сайт → меню → «Установить приложение» / «На главный экран»
- **iOS (Safari)**: «Поделиться» → «На экран Домой»

Приложение работает офлайн после первой загрузки.

## Размещение на GitHub Pages

1. Создайте репозиторий
2. Загрузите все файлы из этой папки в корень (или в docs/)
3. Settings → Pages → Deploy from branch → main / root (или /docs)
4. Готово: `https://ВАШ_ЮЗЕР.github.io/РЕПО/`

## Файлы

- `index.html` — всё приложение
- `manifest.json` — настройки PWA
- `sw.js` — service worker (кэш)
- `icon-192.png` / `icon-512.png` — иконки

Тексты сообщений полностью соответствуют вашим шаблонам для каждого зала.
